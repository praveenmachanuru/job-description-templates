# Job Description Templates

Clean, reusable job description templates for common hiring needs. All examples are generic and not from any real client or company.

## What a good job description includes

1. **Job title:** Use the standard title candidates search for.
2. **Summary:** Two or three lines on the team, the purpose of the role and why it matters.
3. **Responsibilities:** Five to eight specific bullets, starting with action verbs.
4. **Required skills:** Only what the role really needs.
5. **Good to have:** Skills that help but aren't mandatory.
6. **Experience and education:** A range, not a single number.
7. **Details:** Location, work mode, employment type and the hiring process.

Keep it under one page. Long lists of requirements put off good candidates.

## How I adapt a template

1. Take an intake call with the hiring manager and note the must-haves and the nice-to-haves.
2. Fill the template using the manager's words, then simplify the language.
3. Check the title and skills against what candidates actually search for.
4. Share a draft with the hiring manager and revise it before posting.
